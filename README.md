# tpGroupe_dev-frontend-et-audit

Projet : Développer la partie front-end et Audit d'une application.

## Technologies

Ce projet est basé sur un écosystème moderne pour le front-end et les tests.

**Dépendances principales (Production) :**
- **Framework** : Vue 3 (`^3.5.44`)
- **Langage** : TypeScript (`~6.0.3`)
- **Routage** : Vue Router (`^5.4.0`)
- **Backend / BDD** : Firebase (`^13.1.0`)

**Dépendances de développement (Dev) :**
- **Outil de build** : Vite (`^8.3.5`)
- **UI / Design** : Tailwind CSS (`^4.3.4`) + DaisyUI (`^5.7.50`)
- **Tests** : Cypress (`^16.2.1`), Jest (`ts-jest ^29.4.15`) et Supertest (`^7.3.1`)
- **Typage & Config** : `@types/node` (`^24.19.2`), `@vitejs/plugin-vue` (`^6.0.10`), `@vue/tsconfig` (`^0.9.1`), `vue-tsc` (`^3.3.13`)

## Prérequis

Avant de commencer, assurez-vous d'avoir installé sur votre machine :
- [Node.js](https://nodejs.org/) (version LTS recommandée, compatible avec Vite 8)
- Un gestionnaire de paquets (npm, yarn ou pnpm)
- [Git](https://git-scm.com/)
